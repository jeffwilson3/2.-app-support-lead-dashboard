## ✨ Features
* **1-Click Segmented Toggles**: Instant binary switching for `Follow Up (Yes / No)` and `Discuss with Mindy (Yes / No)`.
* **Business Unit Filter**: Dropdown filter to view applications by their specific business unit track.
* **Dynamic KPI Bar & Deep Filtering**: Filter apps by follow-up status, Mindy agenda tag, or onboarding phase with active glow states.
* **Auto-Persistence**: Everything typed into notes, toggles, and daily logs auto-saves to local browser storage (`localStorage`).
* **Executive Briefing Generator**: 1-click export of markdown summaries ready for Slack, Webex, email, or executive status decks.
